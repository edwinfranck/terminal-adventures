# TERMINAL ADVENTURES

Apprendre **Linux** et la **logique algorithmique** en jouant, dans deux univers.

**▶ [Jouer](https://edwinfranck.github.io/terminal-adventures/)**

| Univers | Ce qu'on apprend | Comment on joue |
|---|---|---|
| 🏴‍☠️ **Grand Line** — One Piece | terminal, système de fichiers, droits, filtres | on tape de **vraies commandes** dans un vrai VFS : `ls` `cd` `grep` `chmod` `ln -s` `tar`, les tubes `\|`, les jokers `*` |
| 🗡 **Le Système** — Solo Leveling | algorithmique | on **écrit un programme**, on l'exécute, le chasseur obéit : boucles, tests, fonctions, variables |

**38 niveaux**, 11 chapitres, une histoire du début à la fin. Indices payants en XP, coup de main automatique quand on bloque, débrief pédagogique après chaque niveau. Le copier-coller est bloqué : tout se tape à la main.

## Technique

Vanilla ES modules. **Zéro dépendance, zéro build, zéro serveur applicatif** — c'est du HTML, du CSS et du JS. Le moteur ne connaît aucun gameplay : chaque univers est un **plugin** (`load · reset · test · arsenal · help`), et son contenu tient dans des fichiers JSON.

Aucun chemin absolu : le site fonctionne à la racine d'un domaine comme dans un sous-dossier.
